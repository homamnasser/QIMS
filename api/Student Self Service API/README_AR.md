# مجموعة Bruno للطالب

تغطي هذه المجموعة جميع مسارات الموبايل الخاصة بالطالب وعددها 17 طلبًا.
تستخدم Access Token قصير العمر لمسارات البيانات، وRefresh Token مستقلًا
وأحادي الاستخدام لمسار التجديد فقط.

## ترتيب التشغيل

1. اختر بيئة `Local`.
2. شغّل `01 Login as Student` لحفظ `studentToken` و`refreshToken`.
3. شغّل `02 Verify Mobile Session` للتحقق من هوية الطالب.
4. شغّل طلبات `03` إلى `14` و`17` لاختبار بيانات الطالب المقيدة بهويته.
5. شغّل `15 Refresh Mobile Tokens` عند الحاجة؛ سيستبدل الرمزين تلقائيًا.
6. شغّل `16 Logout` لإبطال زوج رموز الجهاز ومسح المتغيرين المحليين.

طلب `05 Get My Courses` يحفظ أول معرّف كورس في `courseId`، ويستخدمه طلب
`06 Get My Course Schedule` تلقائيًا. يمكن تعديل القيم من بيئة `Local`.
طلبات النتائج والشهادات تستخدم `finalResultId` و`certificateId`، ولا تُرجع
أي سجل لا يخص الطالب المصادق عليه حتى لو غُيّر المعرّف يدويًا.

## حدود الأمان

- لا تقبل مسارات البيانات `studentId` أو هوية طالب يختارها العميل.
- تستخدم جميع طلبات البيانات `studentToken` فقط.
- يستخدم طلب التجديد `refreshToken` فقط.
- هذه المجموعة للموبايل ولا ترسل Cookies جلسة لوحة الويب.
- بيانات الدخول الافتراضية مأخوذة من `TestDataSeeder` ومخصصة للاختبار المحلي.
